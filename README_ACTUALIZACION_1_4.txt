MELLIFERA 1.4 - WEB Y SENSORES
=============================

Publicar TODO el contenido de esta carpeta directamente en la raíz del repositorio de GitHub Pages.

Cambios principales:

- Inicio con animaciones, brillo, parallax y cinta de sensores.
- Panel con desplazamiento natural, sin el scroll interno trabado.
- Sesión activa y cierre de sesión en la barra superior.
- Estado visual por colmena para TEMP, HUM, MOV, RUI, CO2, NH3 y POS.
- Actividad en piquera cuando MOV es mayor que cero y la lectura es reciente.
- Alarma visual grande cuando POS es distinto de cero.
- Gases y ruido por colmena y en el resumen general.
- Caché PWA actualizada a mellifera-app-v5.

Después de publicar:

1. Abrir https://app.mellifera-technology.com
2. Presionar Ctrl + Shift + R.
3. Si conserva archivos anteriores: F12 > Application > Service Workers > Unregister > Storage > Clear site data.
